# GroceryMate

GroceryMate is a small offline-first grocery list PWA designed for personal iPhone use.

## Features

- Add grocery items quickly
- Group items by category
- Optional store and note fields
- Mark items as bought/not bought
- Save favourites for one-tap re-adding
- Recent items strip
- Search and filters
- Copy/share list as text
- Export/import JSON backup
- Offline support after first load
- Add to iPhone Home Screen from Safari

## GitHub Pages

To publish:

1. Open repository **Settings**.
2. Go to **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/** root.
5. Save.

The app will be available at:

```text
https://jnikhanj.github.io/grocerymate/
```

## iPhone install

1. Open the GitHub Pages link in Safari.
2. Tap the Share button.
3. Tap **Add to Home Screen**.
4. Open **Groceries** from the Home Screen.

## Privacy

Grocery data is stored locally in Safari storage on the phone. It is not stored in the GitHub repository.
